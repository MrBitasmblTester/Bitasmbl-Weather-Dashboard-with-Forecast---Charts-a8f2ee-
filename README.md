# Bitasmbl-Weather-Dashboard-with-Forecast-&-Charts-a8f2ee-

## Description
Build a web application that displays current weather, multi-day forecasts, and visualizes trends with charts. The project focuses on integrating APIs, dynamic front-end updates, and data visualization for an interactive user experience.

## Tech Stack
- FastAPI
- Java
- React

## Requirements
- Fetch real-time weather data from a public API
- Display multi-day weather forecasts with clear UI elements
- Visualize temperature, humidity, or other metrics with charts
- Support user interactions, such as searching by city
- Optionally cache API responses to improve performance

## Usage
- Run FastAPI backend with your preferred ASGI server.
- Run Java services with your Java runtime.
- Start React app with your React tooling.

## Implementation Steps
1. Set up FastAPI project for weather API integration.
2. Integrate public weather API for real-time data and forecasts.
3. Implement optional caching layer in FastAPI.
4. Expose weather and forecast data via FastAPI endpoints.
5. Create React UI for search by city and displaying forecasts.
6. Add React chart components for metrics visualization.
7. Integrate React frontend with FastAPI endpoints.
8. Implement Java components required by the application.

## API Endpoints
- GET /weather/current
- GET /weather/forecast
